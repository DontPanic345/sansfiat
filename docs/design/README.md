# Design

What Sans Fiat should be: the vision, plus one file per mechanic with its rules and numbers. Alan writes and owns these files.

Relay sessions read them and never edit them. A spec builds what these files say. A question they don't answer goes to Alan at spec sign-off, and a design question that comes up mid-build is settled from these files and the spec, with the choice noted in the PR.

Nothing here comes from the prototypes' docs, which describe what was built rather than what the game should be.
